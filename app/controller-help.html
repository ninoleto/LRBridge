LRBridge Web Controller Help

Local browser control surface for Adobe Lightroom Classic through LRBridge.

What the Web Controller is for

LRBridge Web Controller is a local browser control panel for Lightroom Classic. It lets you adjust Develop sliders, reset individual sliders, run Lightroom actions, and see slider values reported by Lightroom.

This release runs on Windows and controls Adobe Lightroom Classic, not the cloud-based Lightroom app. Phones and tablets can access the Web Controller on the local network while LRBridge and Lightroom Classic run on the Windows computer.

Bitfocus Companion is optional. You can use the Web Controller with just LRBridge and Lightroom Classic.

The Web Controller started as a practical side tool for testing LRBridge without configuring external hardware. It became useful on its own, especially for touchscreens, tablets, phones, secondary monitors, laptops, and other browser-capable devices.

The original idea behind LRBridge

LRBridge started from a real problem: Loupedeck Live had exactly the kind of knobs Lightroom Classic needs, but the official software did not give that hardware the experience it deserved.

After Logitech acquired Loupedeck, relying on the official software layer became the weak point. Bitfocus Companion gave the device a second life outside the original software stack.

Bitfocus Companion is a control-surface and automation application used to turn devices like Stream Deck, Loupedeck, Razer Stream Controller, and other supported hardware into customizable buttons, knobs, pages, and triggers. It is widely used in AV, broadcast, production, streaming, and custom control setups.

That solved the hardware side of the problem, but not direct Lightroom slider control. Companion can trigger shortcuts and send commands through supported integrations, but it cannot adjust Lightroom's Develop sliders on its own.

Other Lightroom control solutions already exist. MIDI2LR is solid for traditional MIDI controller setups, and LrSuperKeys is excellent for keyboard and mouse-wheel based control. Both are worth recommending for their intended use.

The problem is that neither approach is a clean fit for this Companion-first setup.

That is where LRBridge comes in. Companion sends simple HTTP commands to LRBridge. The LRBridge Lightroom plugin receives those commands from inside Lightroom Classic and applies the requested slider change, reset, or action.

The result is a direct local control path for Lightroom Classic that works with Companion, browsers, phones, tablets, touchscreens, PowerShell, curl, scripts, HTTP request tools, and other button-deck-style devices.

Security and network exposure

The Web Controller and API are intended only for trusted private networks. No login or password is currently required. Do not expose ports 17890, 17891, or 17892 publicly, including through Tailscale Funnel, a public reverse proxy, or a public cloud tunnel. On shared or event Wi-Fi, restrict access with the operating-system firewall or do not run remote access.

Bitfocus Companion integration methods

Use LRBridge with Companion in one of two ways

LRBridge can be controlled from Bitfocus Companion through Companion's built-in HTTP request tools, or through the native LRBridge Companion module.

In both cases, Companion sends an HTTP command to LRBridge, and the Lightroom plugin applies the requested slider change, reset, or action inside Lightroom Classic. 

Loupedeck device -> Bitfocus Companion -> LRBridge app -> LRBridge Lightroom plugin -> Lightroom Classic

Method 1: Companion Generic HTTP Requests

Use Companion's built-in HTTP request tools to map LRBridge commands to Companion buttons, pages, and supported hardware controllers.

This method works with tools already integrated in Companion and does not require the native LRBridge Companion module. The Builder page provides copy-ready commands for slider adjustment, slider reset, and Lightroom actions.

Open Bitfocus Companion HTTP Builder

Method 2: Native LRBridge Companion module

Use the native LRBridge Companion module for a cleaner Companion setup. This lets you choose LRBridge sliders and actions from Companion dropdown menus, instead of manually copying HTTP paths.

Companion module GitHub repo:
https://github.com/ninoleto/companion-module-ninoleto-lrbridge

If the module is not available in the official Companion build yet, use the GitHub repo for the current development version and setup instructions.

Beyond Companion setup, the HTTP Builder is also useful for testing, scripting, curl, PowerShell, browser shortcuts, Stream Deck HTTP/request plugins, and any other tool that can send HTTP requests.

PowerShell example

LRBridge accepts HTTP requests to adjust Lightroom sliders and run actions.

PowerShell can send a command directly to Lightroom through LRBridge: 

curl.exe "http://127.0.0.1:17891/adjust?slider=Exposure&amount=1"

For more commands and ready-to-copy examples, open the HTTP Builder.

Web Controller and API ports

These are the default addresses on the computer running LRBridge. Port 17892 opens the browser pages; port 17891 accepts commands from other applications. On another device, use the computer's network address shown in LRBridge instead of 127.0.0.1.

ServiceLocal URLPurpose
Web Controller http://127.0.0.1:17892 Open the controls for Lightroom in your browser.
This Help page http://127.0.0.1:17892/help Read setup instructions and learn how to use the controls.
API for Companion and scripts http://127.0.0.1:17891 Send commands from Companion, PowerShell and other applications.

Known issues and limitations

How LRBridge controls Lightroom Classic

LRBridge uses Adobe Lightroom Classic’s official plug-in SDK and Windows interface automation.

Many editing controls use the SDK to apply changes without locating or clicking buttons in Lightroom’s interface.

Other controls work by operating Lightroom’s own on-screen interface. These depend on Lightroom’s current layout and state. They may respond less reliably, and LRBridge may not always be able to confirm their current state.

Controls that use interface automation include:

  • Healing → Remove → Selected: Add, Subtract, Cancel and Remove
  • Lens Blur: Subject Focus and Point / Area Focus
  • Lens Blur → Brush Refinement: open/close, Focus/Blur, Amount, Size, Feather, Flow, Auto Mask and resets

If one of these controls does not respond, check and use the corresponding control directly in Lightroom Classic.

Update delays and temporarily unavailable buttons

Lightroom Classic may apply a change before the Web Controller displays the updated value or button state.

After using an action button, allow Lightroom time to respond before using it again. Repeated clicks may queue additional actions that run later.

Some buttons briefly become unavailable during or after edits to allow Lightroom time to update. This includes Auto Tone and Auto White Balance after slider changes. Undo and Redo may also have a short delay. Wait until the button becomes available again.

Understanding messages

  • Loading means the controller is waiting for values from Lightroom, usually after opening the page or changing photos.
  • Unavailable means the control cannot currently be used or its value cannot be read. It does not mean the value is zero. Availability may depend on the selected photo, active Lightroom tool, photo type or Lightroom version.
  • Connection or error messages can indicate a connection problem, a missing update or an action that could not be completed. Read the specific message and check Lightroom for an open dialog, ongoing processing or an error.
  • Command sent means the request has been submitted. It does not confirm that Lightroom has applied the change or finished an edit, export or AI operation.

LRBridge cannot verify the contents of Lightroom’s copied settings or confirm every result when settings are pasted to multiple photos. Review the affected photos in Lightroom Classic, especially when masks or AI-based edits are involved.

If the controller stops responding

Check the Web Controller’s connection status and make sure:

  • LRBridge is running.
  • The LRBridge plug-in is enabled in Lightroom Classic.
  • A photo is selected.
  • Lightroom is in Develop when using editing controls.
  • No Lightroom dialog is blocking interaction.

Allow Lightroom to finish any current processing. If the Web Controller remains disconnected, reload the browser page.

Moving Lightroom between monitors can interrupt the Web Controller’s updates and responsiveness, including ordinary sliders. If this happens, try switching Lightroom to Library and then back to Develop, then allow time for the controller to resume updating.

Control and feedback limitations

Healing → Remove → Selected Add/Subtract

Experimental: Add/Subtract use Windows interface automation, may stop responding and do not report the active mode. If they fail, use Add/Subtract directly in Lightroom.

Healing → Dust

LRBridge controls Dust Apply on/off and Reset by applying two included presets in Lightroom Classic. If those presets are not installed, these buttons are unavailable. Dust Size, Visualize Spots and Threshold do not require the presets.

This setup is only necessary if you want to use Dust Apply or Reset through LRBridge. See Set up the Lightroom plug-in for instructions.

LRBridge’s current Dust implementation is restricted to Lightroom Classic 15.4.1. Support for other versions has not been established.

Point Color → Visualize Range

LRBridge can switch Visualize Range on or off, but the Web Controller does not display its current state. Check Lightroom Classic to see whether it is enabled.

Lens Blur focus controls

Focus Range (near/far) uses the Lightroom SDK. Subject Focus, Point / Area Focus and Brush Refinement use Windows interface automation. Create New Refinement directly in Lightroom; the installed SDK has no documented action to create it. Focus-mode feedback may lag or be unavailable; check Lightroom if the displayed mode is unclear.

Copy / Paste Settings

Choose the settings categories in Lightroom’s Copy Settings dialog. Use Quick Copy Settings to copy the active photo’s current settings, select destination photos, then Paste Settings. Copying directly in Lightroom also works; Quick Copy is not required. Allow Lightroom to process AI edits, then review the destination photos. Technical feedback is in Details.

Red Eye: Adjust Pupil Size and Darken directly in Lightroom.

Masking: Adjust Brush Size, Feather, Flow, Density and Auto Mask; Radial Gradient Feather; and Color Range Refine directly in Lightroom. These tool settings have no documented controls in the installed SDK. Ordinary mask adjustment sliders are supported separately.

Information read from Lightroom’s interface

Some displayed information depends on reading Lightroom’s interface, including:

  • Camera Profile choices and names
  • Lens Blur Visualize Depth state

This is separate from how LRBridge sends changes to these settings. If the interface information cannot be read, the corresponding controls may temporarily appear unavailable or may not display their current state correctly.

Unsupported controls

Changing lens profiles is not supported in LRBridge.

Select and configure your lens profile directly in Lightroom Classic.

Set up the Lightroom plug-in

The plug-in is included with LRBridge. Find the folder containing LRBridge.exe. Inside it, the lightroom folder contains LRBridge.lrplugin — this is the plug-in folder you need to select.

On the computer running LRBridge:

  1. Open Lightroom Classic.
  2. Go to File → Plug-in Manager and click Add.
  3. Browse to your LRBridge folder, open lightroom, and select LRBridge.lrplugin.
  4. Make sure the plug-in is enabled, then click Done.

Keep LRBridge running while using the Web Controller.

Using a newer LRBridge folder? Make sure Lightroom loads the plug-in from that same folder. Remove the older LRBridge entry from Plug-in Manager and add the current one.

Healing → Dust: To use Apply on/off and Reset through LRBridge, you need to add two Dust presets to Lightroom. Close Lightroom Classic and run Install Dust Presets.cmd from your LRBridge folder. This adds both presets automatically. Reopen Lightroom when it finishes. If Apply and Reset already work, you can skip this step.
