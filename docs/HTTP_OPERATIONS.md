# HTTP operation inventory

Generated by `npm run generate:http-reference` from registered server routes. Paths are route identifiers, **not complete or permanently reusable commands**. This table is an index, not an executable example. Parameterized route segments use `:name`.

Use these paths directly on port **17891**; prepend `/api` only for the Web Controller proxy on port **17892**. See [Builder parameters and workflow requirements](HTTP_WORKFLOWS.md). Internal routes are recorded for completeness, not offered as actions. HTTP acceptance is not confirmed Lightroom execution.

- **ordinary**: Ordinary Builder commands use these routes with validated parameters. Acceptance means queued, not confirmed Lightroom execution; a route alone is not a complete command.
- **read**: State/discovery. Some reads request asynchronous SDK feedback; observe availability and freshness.
- **workflow**: Not generated as a permanent URL. Use the controller or documented multi-step workflow with exact parameters, context, gesture lifecycle and results.
- **internal**: Internal plug-in protocol. Not a controller action or reusable URL.
- **deprecated**: Legacy/unsupported entry; use the current controller workflow.
