# HTTP operation inventory

Generated by `npm run generate:http-reference` from registered server routes. Paths are route identifiers, **not complete or permanently reusable commands**. No required query fields are omitted from an executable example: this table is an index, not an executable example. Parameterized route segments use `:name`.

The ordinary Builder retains its command/value choices. Every other public route is indexed below; workflow generation gaps are explicit. [Workflow requirements](HTTP_WORKFLOWS.md). Internal routes are recorded for completeness, not offered as actions.

- **ordinary**: Existing ordinary Builder families; validated current-context commands. Acceptance means queued.
- **read**: State/discovery. Some reads request asynchronous SDK feedback; observe availability and freshness.
- **workflow**: Not generated as a permanent URL. Use the controller or documented multi-step workflow with exact parameters, context, gesture lifecycle and results.
- **internal**: Internal plug-in protocol. Not a controller action or reusable URL.
- **deprecated**: Legacy/unsupported entry; use the current controller workflow.
